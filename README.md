# Petrus Method

A complete single-page reference for Lars Petrus's method of solving Rubik's Cube for speed.

## Contents

All pages from [lar5.com/cube](https://lar5.com/cube) collated into one document:

- Basic cube facts and terminology
- Steps 1–7 with interactive Roofpig cube animations
- Step 3 edge orientation index (2, 4 and 6 bad edges)
- Step 4b full tricks index
- Step 5+6 and Step 6+7 full algorithm indices, including every case in corner groups A–G
- Block building patterns
- 13 annotated solution examples
- Physical and mental speed tips
- Algorithm quick reference

## Usage

Open in Safari. Requires an internet connection to load the Roofpig animation library and the case diagrams and photos, which are loaded from lar5.com.

To print: load the page fully, wait for all cube diagrams to render, then print. The cube widgets will snapshot to static images automatically.
